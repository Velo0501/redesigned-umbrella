# 有限会社鈴泰電気 ホームページ

添付されたデザインをもとにした、白と緑のスマートフォン対応サイトです。庭のライトアップを大きく見せるトップ画面と、写真付きの事業紹介5項目で構成しています。外部ライブラリや外部画像の読み込みはありません。写真風の画像はAI生成のイメージで、施工実績写真ではありません。

## 開発・確認

Node.js 20 以上で、リポジトリのディレクトリから実行します。依存パッケージのインストールは不要です。

```sh
npm run dev
```

既定ポートは 3000。`PORT=3001 npm run dev` で変更できます。

## 公開用ファイル

```sh
npm run build
npm start
```

`dist/` を静的ホスティングへ配置できます。公開・ドメイン設定は別途必要です。電話リンクから端末の電話アプリを起動し、地図リンクは Google マップの住所検索を開きます。問い合わせフォームや顧客情報の収集は実装していません。

`dist/suzuyasu-denki.html` は画像・CSS・JavaScriptを内蔵した確認用ファイルです。この1ファイルをダウンロードしてブラウザで直接開けます。

## GitHub Pages での確認用公開

公開ブランチ `gh-pages` に `public/` の内容を配置する方式です。GitHub のリポジトリ Settings → Pages で、Source を **Deploy from a branch**、Branch を **gh-pages**、フォルダーを **/(root)** にして保存します。アセットのパスはリポジトリ名付きのURLでも動く相対パスです。

会社名・所在地・電話番号が掲載されたページを、確認用として公開することはユーザーの承認済みです。公開済みという判断は、Pages の設定と実際のサイト応答を確認してから行ってください。

## 内容の更新

- 本文・会社情報：`public/index.html`
- 色・レイアウト：`public/styles.css`
- モバイルメニュー：`public/main.js`
- AI生成のイメージ画像：`public/assets/`

掲載内容は会話で提供された会社名・住所・電話番号・事業内容・対応地域に基づきます。営業時間、資格、施工実績、料金などの未確認情報は掲載していません。公開前に会社情報と掲載文章を確認してください。
